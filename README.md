An entry for the [make.fun](https://make.fun/bounty/u-hamsyh-funniest-one-line-out-of-office-reply-5490c1c8) bounty **"Funniest One-Line Out-of-Office Reply"**.

`main.ts` (Node 22) writes a single one-line out-of-office reply to `/output/entry.txt`:

> I'm out of the office until Monday — if it's urgent, it can wait; if it can wait, it's waiting until Monday.

The joke is the inversion: urgent things can wait, and things that can wait are definitely waiting — so nothing gets answered until Monday. It reads like a real away message, lands on the first read, and avoids the usual beach / inbox / "limited access to email" lines.

## Run

```sh
node main.ts
cat /output/entry.txt
```

The entry is 108 characters, one line, within the gate of 1–160 characters.
